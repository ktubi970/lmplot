# LLM Audit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construire un espace Streamlit local et indépendant pour importer, versionner, évaluer et auditer jusqu’à 100 000 réponses de LLM, avec rapports reproductibles et causalité strictement contrôlée.

**Architecture:** Le package Python `llm_audit` porte tout le domaine, le stockage DuckDB/Parquet, les analyses et les rapports. `llm_audit_app.py` et `llm_audit/ui/` ne font qu’orchestrer les services et afficher l’`AuditReport`; R et le LLM local sont des adaptateurs facultatifs. Les données et runs sont append-only après validation ou finalisation.

**Tech Stack:** Python 3.10+, Pydantic 2, DuckDB, PyArrow/Parquet, pandas, NumPy, SciPy, statsmodels, krippendorff, Jinja2, RFC 8785, Streamlit, Plotly, pytest, Hypothesis, pytest-cov, Rscript facultatif.

**Spec:** `docs/superpowers/specs/2026-08-15-llm-audit-design.md`

## Global Constraints

- Ne modifier aucun calcul, écran ou test historique LM/GLM/GLMM sauf les fichiers de lancement et de packaging explicitement listés dans ce plan.
- Préserver toutes les modifications locales préexistantes; inspecter `git diff -- <file>` avant chaque fichier déjà modifié.
- Streamlit ne calcule aucune mesure scientifique et ne reconstruit aucune conclusion.
- Aucun appel réseau non-loopback n’est permis; aucun client cloud n’entre dans le MVP.
- R et le LLM local restent facultatifs et leur absence ne bloque que leur méthode.
- Le rapport canonique est `llm-audit-report/1.0`; l’empreinte analytique utilise RFC 8785 puis SHA-256.
- Le niveau de confiance est 95 %, Benjamini-Hochberg utilise 0,05 et le bootstrap utilise 2 000 réplications.
- Les identifiants techniques sont UUIDv7; les identifiants métier importés restent opaques.
- Les objets validés et les runs terminaux sont immuables.
- Toute association non identifiable reste libellée comme association.
- Les tests historiques réussissant au début de l’exécution doivent encore réussir à la fin.
